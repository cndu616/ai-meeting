# tests 目录须知

- **`vi.waitFor` 的坑**：回调返回 `false` 不算失败、不会重试，**必须抛错**（或内部 `expect` 抛出）才会被 waitFor 当作"未就绪"继续轮询。写等待型断言一律用抛错式回调，否则断言形同虚设、测试假绿。（来源：2026-10 评审，小李在 a-batch-race-repro.test.ts 踩过）
- **`a-batch-race-repro.test.ts` 是红用例**：它复现 pause→resume 窗口期竞态（评审 A 批验收标准），当前**应当保持红**，A 批修法落地后转绿。谁看到它失败先别"顺手修"。
- 时序型用例（gateAt 挂起回合）注意：多时序采样，挂起点换位置各跑一遍，防止单一时序绿。
